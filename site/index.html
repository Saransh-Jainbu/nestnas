( 01 ) Features

The parts of a cloud plan you actually use.

Cloud storage plans charge every month. NestNAS provides the same core features on a laptop and a drive you already own.

Phone backup

Back up photos and videos from your phone.

Select photos and videos, or a whole folder, and NestNAS copies only what the NAS does not already have. Duplicates are skipped, files with the same name are both kept, and nothing is overwritten or deleted.

Encrypted at rest

Encrypted before it is written to disk.

Each file has its own key. If the laptop or drive is lost, the contents are unreadable.

Gallery & viewer

Photo gallery and viewer.

Thumbnails, a full-screen viewer, swipe, video seeking. Decrypted on the fly, never cached.

External drives

Removable drives are handled safely.

Use a USB or external drive as storage. If it is unplugged, NestNAS pauses, shows a warning and never writes to the laptop's internal disk instead. When the drive returns, even at a different mount point, it resumes automatically.

( 02 ) Security

Security design.

  1. i.

    One program, no dependencies.

    Written in Go using only the standard library, so there are no third-party packages to audit and nothing contacts external services. The full source is available to read.

  2. ii.

    Encrypted in transit and at rest.

    In transit: TLS 1.3 only, using a private certificate authority restricted to private network addresses. At rest: AES-256-GCM, with keys protected by your passphrase (memory-hard scrypt) and a recovery key.

  3. iii.

    Documented limitations.

    File names, sizes and dates are not encrypted; only contents are. The file format is new and has not been independently audited.

last chunkflagged final
  • unique key per file (HKDF from the master key)
  • nonce = chunk counter, never reused
  • header + "last" flag are authenticated
  • flip, drop, swap or truncate a chunk: detected

( 04 ) Get started

Install in three steps.

01

Build

You need Go 1.18 or newer. Packaged installers arrive with the first release.

terminal
# get it
$ git clone https://github.com/Saransh-Jainbu/nestnas.git
$ cd nestnas && make build
# run it now, and on every start
$ ./nestnas service install
02

Configure

Open localhost:8080 and choose the storage allowance, the storage location (an external drive works) and whether to encrypt. Store the recovery key somewhere safe.

03

Add a device

On the same network, open the device setup page shown in the dashboard, install the certificate, add the dashboard to your home screen, and use the Backup tab.

( 05 ) Limitations

Known limitations.

  • Pre-1.0 software. It is tested end to end, but it should not be the only copy of irreplaceable data.
  • Not audited. The encryption uses standard primitives, but the file format is new and has not been independently reviewed.
  • Developed on Linux. Windows and macOS builds compile and share the same code, but have not yet been tested on real systems.
  • iOS limitations. Safari cannot upload in the background, so the page must stay open during a backup. The iOS Files app cannot mount WebDAV drives; use the web app instead.
  • Lost passphrase. If both the passphrase and the recovery key are lost, the encrypted files cannot be recovered.
